## Enable GitHub Pages (fixes 404)

**Do this once — takes 1 minute:**

1. Open https://github.com/atchyut96379/My_Portfolio/settings/pages  
   (You must be signed in to GitHub)
2. Under **Build and deployment** → **Source**, choose **Deploy from a branch**
3. **Branch:** `main` → folder **`/ (root)`**
4. Click **Save**
5. Wait 2–5 minutes, then open: **https://atchyut96379.github.io/My_Portfolio/**

If you still see 404 after 5 minutes, refresh the page or try in an incognito window.
