# Data Analysis Demo

Sample **sales data analysis** project for freelance portfolio.

## Skills shown

- CSV data loading and cleaning
- Aggregations (by region, product, month)
- Summary report generation
- Chart export (matplotlib)

## Run

```powershell
cd portfolio/data-analysis-demo
python -m pip install -r requirements.txt
python analyze.py
```

## Output

- `output/report.txt` — text summary for clients
- `output/summary_chart.png` — bar chart by region

## Use in proposals

> "I analyzed sales CSV data, calculated KPIs (total revenue, AOV, top region/product), and delivered a report + chart."
