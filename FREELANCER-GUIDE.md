# Freelancer Guide — How to Get Your First Clients

Yes — **portfolio + freelancing is a much better approach** than mining for your ₹60L goal. This guide is step-by-step for someone in India working **after job hours**.

---

## Step 1 — Put your work online (this week)

### A. Create GitHub account
1. Go to [github.com](https://github.com) → Sign up (free)
2. Choose a professional username (e.g. `yourname-dev`, not `coolboy123`)

### B. Upload this project
Run in PowerShell from `D:\Projects\Portfolio`:

```powershell
git init
git add .
git commit -m "Portfolio: Bitcoin Miner desktop app + data analysis demo"
```

Create a new repo on GitHub (name it `bitcoin-miner` or `portfolio`), then:

```powershell
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/bitcoin-miner.git
git push -u origin main
```

### C. Enable free portfolio website
1. GitHub repo → **Settings** → **Pages**
2. Source: **Deploy from branch** → `main` → folder `/portfolio`
3. Your site: `https://YOUR_USERNAME.github.io/bitcoin-miner/`

Edit `portfolio/index.html` — replace **Your Name**, email, GitHub links.

## Step 2 — Where to find clients (ranked for beginners)

| Platform | Best for | Fees | Start here? |
|----------|----------|------|-------------|
| **Fiverr** | Small fixed-price gigs | 20% | ✅ Yes — create 2-3 gigs |
| **Upwork** | Bigger projects | 10% | ✅ Yes — send proposals |
| **Internshala** | India internships/part-time | Varies | ✅ Good for first experience |
| **LinkedIn** | Local & remote clients | Free | ✅ Post + message |
| **Apna / Naukri** | Part-time tech jobs | Free | ✅ Side income |
| **Local shops** | Websites for small business | Cash | ✅ Walk in with portfolio |

**You don't "approach freelancers"** — you approach **clients** who need work done. Other freelancers are competitors, not clients.

## Step 3 — What to offer first (easy wins)

Start with services you can deliver **this week**:

| Gig | Price (start low) | Your proof |
|-----|-------------------|-------------|
| Python script / automation | ₹500 – ₹2,000 | Bitcoin Miner project |
| Excel/CSV → report + chart | ₹800 – ₹3,000 | data-analysis-demo |
| Fix Python bug | ₹500 – ₹1,500 | GitHub code |
| Simple landing page | ₹2,000 – ₹5,000 | portfolio site |
| Data cleaning (CSV) | ₹1,000 – ₹4,000 | analysis demo |

**First 5 clients:** price low to get **reviews**, not profit.

## Step 4 — How to send your first proposal (copy template)

When you see a job on Upwork/Fiverr/LinkedIn:

```
Hi [Client name],

I can help with [their exact problem — e.g. "Python script to clean Excel data"].

Relevant work:
• Built a Windows desktop app in Python (GUI + API + .exe packaging): [GitHub link]
• Data analysis demo — CSV to report + chart: [GitHub link]
• Portfolio: [your GitHub Pages link]

I am available [evenings/weekends] and can deliver a first draft in [2-3 days].

Happy to do a small paid test task (₹500) so you can check quality before the full job.

Thanks,
[Your name]
[WhatsApp if comfortable]
```

**Rules:**
- Mention **their** project in line 1 (not generic spam)
- 2 links max — GitHub + portfolio
- Short — clients skip long messages

## Step 5 — Daily routine (2 hours after work)

| Time | Action |
|------|--------|
| 30 min | Send **5 proposals** on Upwork/Fiverr |
| 30 min | Improve portfolio / learn one skill |
| 30 min | Practice or finish one small project |
| 30 min | LinkedIn — comment + message 2 business owners |

**5 proposals × 30 days = 150 chances** — you will get replies.

3. **"I will fix bugs in your Python code"** — ₹500 start

## Step 7 — Avoid these mistakes

| Mistake | Fix |
|---------|-----|
| No GitHub / empty profile | Upload projects this week |
| Generic "I am hard worker" bio | List **specific** projects + links |
| Only mining for income | Stop — focus freelance hours |
| Waiting for perfect portfolio | **Good enough + live** beats perfect + hidden |
| Giving up after 10 proposals | Need 50–100 for first client |

## Step 8 — Income path to help debt (realistic)

| Month | Target | How |
|-------|--------|-----|
| 1 | ₹5,000 – ₹15,000 | 2–3 small Fiverr/Upwork gigs |

This won't clear ₹60L in 6 months — but it's **real money** mining never gave you.
